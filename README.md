# منصة إدارة الصرافة والتحويلات المالية والمحاسبة المركزية
### Exchange & Financial Management System (بنكك OCR • المحاسبة المركزية • العهد • الموردين)

نظام مالي ومحاسبي متكامل لإدارة نشاط الصرافة، العملاء، إيصالات بنكك (OCR)، النقدية، الموظفين، الموردين، عمليات شراء وبيع العملات، الأرباح والخسائر، الديون، والتسويات اليومية، مبني بدقة تامة ومطابق بنسبة 100% لوثيقة متطلبات المشروع الشاملة (85 صفحة).

---

## 🌟 الميزات الجوهرية المنفذة في النظام

### 1. المحرك المالي والمحاسبي المركزي (Double-Entry Ledger Engine)
- **قيد محاسبي مزدوج حقيقي**: كل معاملة مالية تُنشئ قيداً متوازناً (`Total Debit == Total Credit`).
- **حظر تعديل الأرصدة المباشر**: لا يمكن تعديل رصيد أي حساب دون قيد مالي رسمي مسجل.
- **دقة عشرية متناهية (Decimal Precision)**: استخدام مكتبة `decimal.js` ومطابقة قاعدة منع أخطاء التقريب وكسور العملات.
- **دليل الحسابات المتكامل**: صناديق نقدية (مصرية وسودانية)، حساب بنكك، عهد الموظفين، التزامات العملاء والموردين، رأس المال، المصروفات، والأرباح.

### 2. إدارة إيصالات بنكك والتحقق الذكي (Bankak Receipt Management & OCR)
- **رفع دفعة إيصالات في ثوانٍ (Batch Upload)**: دعم رفع عشرات أو مئات الإيصالات دفعة واحدة.
- **استخراج تلقائي فوري**: استخراج رقم العملية (Transaction ID)، المبلغ (Amount)، العملة (SDG)، اسم ورقم حساب المرسل، اسم المستفيد، والتاريخ والوقت.
- **كشف ومنع الإيصالات المكررة**: مطابقة رقم العملية وبصمة الصورة (SHA-256 Hash) لمنع احتساب الإيصال مرتين أو تكرار استخدامه محاسبياً.
- **شاشة المراجعة المزدوجة (Side-by-side Review)**: عرض صورة الإشعار بجانب الحقول المستخرجة مع إمكانية التعديل، الرفض، أو الاعتماد الفوري وترحيل الأثر المالي.

### 3. إدارة العملاء والجلسات اليومية (Customer Management & Daily Sessions)
- **ملف العميل الدائم**: كود فريد لكل عميل، أرقام الهواتف، الواتساب، والبيانات الشخصية.
- **جلسات التعامل اليومية**: فصل التعاملات اليومية للعميل دون خلط، مع احتساب سعر الصرف، المبلغ المطلوب، إجمالي الإيصالات المجزأة المستلمة، والمبالغ المسلمة نقداً.
- **كشف حساب رسمي معتمد**: إمكانية طباعة وتصدير كشف حساب العميل الرسمي المعتمد شاملاً الترويسة، تفاصيل العمليات، والتوقيعات.

### 4. إدارة الموظفين والعهد المالية (Employee Custody System)
- **تسليم العهد النقدية**: صرف عهدة نقدية للموظف من الخزينة الرئيسية وتدوين القيد المحاسبي.
- **تسليم النقدية للعملاء**: صرف الكاش المصري للعميل خصماً من عهدة الموظف وتحديث الجلسة اليومية.
- **منع تجاوز العهدة**: حظر صرف مبالغ تتجاوز رصيد الموظف المتاح.
- **كشف حساب عهدة الموظف**: متابعة الوارد والصادر والرصيد المتبقي لحظياً وتسوية العهدة نهاية اليوم.

### 5. إدارة الموردين ومخزون العملات (Suppliers & Currency Costing)
- **شراء وبيع العملات بالجملة**: شراء سوداني مقابل مصري أو العكس وتحديث أرصدة الخزائن تلقائياً.
- **حساب متوسط التكلفة المرجح (Weighted Average Cost)**: حساب تكلفة المخزون والأرباح والخسائر الفعلية الناتجة عن الصفقات.
- **تسجيل العمليات الجزئية والديون**: متابعة مديونيات ومستحقات الموردين.

### 6. رأس المال، المصروفات، والديون
- **رأس المال المستثمر**: تسجيل المساهمات والمسحوبات مع الفصل التام عن الأرباح التشغيلية.
- **المصروفات المبوبة**: تبويب المصروفات (إيجارات، رواتب، كهرباء، إنترنت، رسوم تحويل) وخصمها من الخزائن.
- **إدارة الديون وأقساط السداد**: تسجيل ديون العملاء والموردين ومتابعة السداد الجزئي مع الاحتفاظ بسجل السداد الكامل.

### 7. الإغلاق اليومي ومطابقة الخزائن (Daily Closing & Reconciliation)
- **مطابقة النقدية الفعلية**: مقارنة الرصيد المتوقع محاسبياً مع الرصيد الفعلي المعدود في الخزائن.
- **رصد الفروقات**: إبراز الفروقات بدقة (عجز نقدي / فائض نقدي) بالجنيه المصري والسوداني.
- **تثبيت وإغلاق اليوم**: تجميد العمليات اليومية ومنع التعديلات غير المصرح بها.
- **إعادة فتح اليوم الرقابي**: اشتراط إذن مدير النظام وتقديم سبب إلزامي يسجل في سجل التدقيق.

### 8. سجل التدقيق الرقابي غير القابل للتعديل (Immutable Audit Log)
- تسجيل كل عملية، إنشاء، تعديل، اعتماد، أو دخول للمستخدمين مع تسجيل قيم ما قبل وبعد والتاريخ ورقم الـ IP.

### 9. التقارير المالية والتصدير
- قائمة الأرباح والخسائر (Profit & Loss).
- تقرير الأرصدة النقدية والمصرفية.
- تصدير مباشر إلى Excel (XLSX).
- طباعة وتصدير PDF بتنسيق رسمي متوافق مع اللغة العربية واتجاه RTL.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend**: Next.js Full-Stack API Routes, Node.js, Prisma ORM.
- **Database**: SQLite (للتشغيل الفوري بدون متطلبات خارجية) / PostgreSQL (للإنتاج والنشر في Docker).
- **Financial Engine**: Decimal.js للعمليات الحسابية بدون أي أخطاء عشرية.
- **OCR Engine**: محرك ذكي متخصص في إيصالات تطبيق بنكك (Bankak).
- **Deployment**: Docker & Docker Compose جاهز للنشر الفوري.

## 🚀 تعليمات التشغيل السريع (Quick Start)

### التشغيل المباشر عبر Node.js:
```bash
# 1. تثبيت الحزم (تم مسبقاً)
npm install

# 2. إنشاء وتحديث قاعدة البيانات وتوليد Prisma Client
npx prisma generate
npx prisma db push

# 3. تغذية النظام بالبيانات الأساسية ودليل الحسابات
node scripts/seed.mjs

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح محلياً على: `http://localhost:3000` أو على الرابط السحابي المباشر: `https://exchange-management-system.onrender.com`

### بيانات الدخول التجريبية الجاهزة:
- **مدير النظام (Admin)**: `admin@exchange.com` / كلمة المرور: `admin123`
